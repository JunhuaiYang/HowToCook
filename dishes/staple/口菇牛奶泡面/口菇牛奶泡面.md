# 口菇牛奶泡面

@小弟陈思建 抖音/YouTube 做菜教程字幕整理（2026-11-23）。泡面极致版，奶香奶油味。

```tips
** 难度：★
```

## 预估卡路里

**预估卡路里：550 大卡（每份约 550 大卡）**

## 原料

- 泡面：1 包
- 口蘑：5 朵
- 牛奶：200ml
- 清水：200ml（牛奶和水比例 1:1）

## 做法

1. 口蘑洗净去蒂。
2. 干锅（不放油）下口蘑，盖盖小火焖到口蘑出汁。
3. 用剪刀把口蘑剪成小块。
4. 倒入牛奶和水（1:1），下泡面饼和蔬菜包煮开。
5. 泡面煮开后再煮 1 分钟即可出锅（调料包按平时量放）。

## 小贴士

- 口菇干煸出汁是鲜味的来源，不用油。
- 牛奶让汤变成奶油浓汤味，试过都说妙。
