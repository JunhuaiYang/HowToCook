# 家庭版煎年糕

@小弟陈思建 抖音/YouTube 做菜教程字幕整理（2026-11-23）。

```tips
** 难度：★
```

## 预估卡路里

**预估卡路里：400 大卡（每份约 400 大卡）**

## 原料

- 年糕：300g（切片）
- 韩式辣酱 1 勺、辣椒粉半勺（不吃辣可省）、生抽少许
- 白芝麻：适量

## 做法

1. 年糕切片（厚一点有口感）。
2. 调酱：韩式辣酱 1 勺 + 辣椒粉半勺 + 生抽少许 + 2 勺水，拌匀。
3. 起锅烧油，年糕小火慢煎。
4. 煎到底面微焦（有点烧烤的微焦感）翻面。
5. 两面煎好后倒入酱汁，翻匀裹上。
6. 撒白芝麻出锅。

## 小贴士

- 火候是重点：小火慢煎才外脆里糯，大火外面糊了里面还是硬的。
- 酱汁最后放，避免糊锅。
