# 蒜蓉大虾

@小弟陈思建 抖音/YouTube 做菜教程字幕整理（2026-11-23）。

```tips
** 难度：★★
```

## 预估卡路里

**预估卡路里：160 大卡（每份约 160 大卡，全锅约 500 大卡）**

## 原料

- 大虾：500g（剪开虾背去虾线）
- 大蒜：1 整头（切末）
- 洋葱：小半个（切末）
- 小米辣：2 根（切圈，不吃辣可省）
- 料酒 1 勺、生抽 2 勺、白糖半勺

## 做法

1. 大虾洗净剪开虾背去虾线，加料酒抓匀。
2. 起锅烧油，下洋葱碎、小米辣、蒜末，中火炒出蒜香。
3. 下大虾煎炒到变红。
4. 加生抽、白糖和小半碗水，翻匀。
5. 大火收汁，让蒜蓉汁裹满虾身即可。

## 小贴士

- 蒜末要多、火不要太大，炒成金黄蒜蓉才香不苦。
- 剩下的蒜蓉汁拌饭一绝。
