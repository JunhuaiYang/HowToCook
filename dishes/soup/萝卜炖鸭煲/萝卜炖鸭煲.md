# 萝卜炖鸭煲

@小弟陈思建 抖音/YouTube 做菜教程字幕整理（2026-11-23）。

```tips
** 难度：★★
```

## 预估卡路里

**预估卡路里：120 大卡（每碗汤约 120 大卡，全锅约 800 大卡）**

## 原料

- 鸭子：半只（约 750g，剁块）
- 白萝卜：1 根（约 500g，切滚刀块）
- 姜：1 块（切片）
- 葱结：1 个
- 料酒：1 勺
- 盐、鸡精：适量

## 做法

1. 鸭块冷水下锅，加姜片料酒，焯水后捞出洗净。
2. 起锅烧热油，下鸭块煸炒出油，加姜片、葱结炒香。
3. 加开水没过鸭肉，大火烧开，转小火慢炖 40 分钟。
4. 下萝卜块，继续炖 20 分钟至萝卜透明软糯。
5. 加盐、鸡精调味，再煮 5 分钟即可。

## 小贴士

- 用半只鸭或鸭腿都行，鸭皮油脂多，先煸炒出油汤才香不腥。
- 焯水必须冷水下锅，血沫才能煮出来。
- 汤鲜味来自鸭肉本身，不需要额外浓汤宝。
