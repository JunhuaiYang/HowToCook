# 日式厚蛋烧

@小弟陈思建 抖音/YouTube 做菜教程字幕整理（2026-11-23）。

```tips
** 难度：★★
```

## 预估卡路里

**预估卡路里：280 大卡（整条约 280 大卡）**

## 原料

- 鸡蛋：3 个
- 火腿碎：1 根量
- 葱花：1 根量
- 盐少许、牛奶 1 勺（可选，更嫩）

## 做法

1. 鸡蛋打散，加盐和牛奶，加入葱花、火腿碎拌匀。
2. 方形煎锅（或普通平底锅）刷薄油，小火。
3. 倒一层薄蛋液，铺满锅底，半凝固时从一端卷起。
4. 再刷油，倒第二层蛋液，掀起卷好的蛋卷让新蛋液流到底部。
5. 半凝固再卷，重复 3–4 层。
6. 出锅切段，截面就是整齐的层。

## 小贴士

- 全程小火，蛋液半凝固就卷，全熟会碎。
- 没有方锅用圆锅也行，卷出来是圆卷，味道一样。
