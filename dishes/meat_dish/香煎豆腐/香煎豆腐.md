# 香煎豆腐（小米辣浇汁版）

@小弟陈思建 抖音/YouTube 做菜教程字幕整理（2026-11-23）。

```tips
** 难度：★★
```

## 预估卡路里

**预估卡路里：250 大卡（每份约 250 大卡，全锅约 500 大卡）**

## 原料

- 老豆腐：1 块（约 400g，切小块）
- 淀粉：1 小勺（裹豆腐用）
- 浇汁：生抽 3 勺、香醋 1.5 勺、白糖 1 勺、蚝油少许、淀粉 1 勺、清水半碗
- 小米辣 2 根、蒜末 3 瓣（不吃辣减半）

## 做法

1. 老豆腐切小块，表面薄薄裹一层干淀粉。
2. 浇汁调好：生抽 3 勺 + 香醋 1.5 勺 + 糖 1 勺 + 蚝油少许 + 淀粉 1 勺 + 半碗水，搅匀。
3. 平底锅多放点油，豆腐小火煎到六面微焦（每一面都煎到）。
4. 锅里留底油，爆香小米辣和蒜末。
5. 倒入浇汁煮到浓稠冒泡。
6. 豆腐回锅，翻匀挂汁出锅。

## 小贴士

- 裹淀粉是外壳微焦、内里嫩的关键。
- 汁子酸辣开胃，配米饭能多吃一碗；不能吃辣的把小米辣整个省掉也成立。
