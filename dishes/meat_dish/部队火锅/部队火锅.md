# 部队火锅（家庭版）

@小弟陈思建 抖音/YouTube 做菜教程字幕整理（2026-11-23）。

```tips
** 难度：★
```

## 预估卡路里

**预估卡路里：700 大卡（每份约 700 大卡）**

## 原料

- 部队火锅食材包一份：午餐肉、香肠、豆腐、金针菇、年糕、泡菜、拉面饼
- 肥牛：100g
- 芝士片：1–2 片
- 酱汁：韩式辣酱 2 勺 + 生抽 1 勺 + 糖半勺 + 蒜末 1 瓣 + 清水 2 勺，拌匀

## 做法

1. 所有食材切好，在锅里码成漂亮的一圈圈。
2. 中间放泡菜和韩式辣酱酱汁。
3. 倒开水没过食材大半，盖盖煮开。
4. 煮 5 分钟后放拉面饼和肥牛，再煮 3 分钟。
5. 关火铺芝士片，余温焖化，开吃。

## 小贴士

- 食材自由，冰箱剩菜都能进锅，酱汁才是灵魂。
- 芝士一定要关火再放，余温化开最拉丝。
